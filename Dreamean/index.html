AI API 연동 설정

꿈을 해석하기 위해 API 키가 필요합니다. 입력하신 정보는 본인의 브라우저 안전 영역(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다.

공급자별 가이드
  1. OpenAI Platform 가입
  2. API Keys 탭에서 새 비밀 키(Create new secret key) 생성
  1. Google AI Studio 가입
  2. Get API Key 버튼 클릭 후 새 키 발급 및 복사
  1. Anthropic Console 가입
  2. API Keys 메뉴에서 키 발급 및 복사

DeepSeek, Grok, OpenRouter, 또는 로컬 Ollama(http://localhost:11434/v1) 등의 API 주소와 모델명을 기입하여 연결할 수 있습니다.
